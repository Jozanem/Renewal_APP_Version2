# Renewal App Version 2

## Description
Given the challenge that the main system cannot sent letters to clients automaticall. I created this app to us users to be able to generate letters and send emials by using an excel file. 
This is the second version of the app for renewals:
> Includes agents
> Has bigger email body field
> Can select Number of charecters for the mathcing columns 18 being default
> Has next and previous previes buttons
> Has the path for the attachement folder


## Features
> Generate customized letters 
> Email letters to clients
>

- Python 3.x

## Installation

### 1. Clone the repository
git clone <repository-url>

### 2. Create a virtual environment
python -m venv venv

### 3. Activate the environment
venv\Scripts\activate

### 4. Install dependencies
pip install -r requirements.txt

### 5. Run the application
python letters.py
